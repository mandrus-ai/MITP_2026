Подробное описание

Singleton-класс сетевого клиента.

Singleton-класс TCP-клиента.

Класс обеспечивает единственное подключение к TCP-серверу, отправку сообщений, получение ответов и передачу событий через сигналы Qt.

Класс создаёт и хранит единственное TCP-соединение с сервером, отправляет сообщения, принимает ответы и сообщает о событиях через сигналы Qt.

◆ slotReadyRead() [1/2]

void SingletonClient::slotReadyRead ( )

Читает данные, пришедшие от сервера.

Читает входящие данные от сервера.

Читает данные от сервера и обрабатывает сообщения по разделителю.

Накапливает данные в буфере и отправляет сигнал messageFromServer().

Сервер может прислать большой ответ частями или несколько ответов сразу. Поэтому данные сначала накапливаются в буфере, а затем извлекаются только полностью полученные сообщения, разделённые символом QChar(1).

Метод считывает все доступные байты, добавляет их в буфер и отправляет сигнал messageFromServer().
