Подробное описание

TCP-сервер, принимающий подключения клиентов и обрабатывающий команды.

Класс создаёт QTcpServer, слушает входящие подключения, читает данные из сокетов и отправляет ответы, полученные от функции parsing().

◆ slotServerRead()

void MyTcpServer::slotServerRead ( )

Читает данные от клиента, вызывает обработчик команд и отправляет ответ.

Читает запросы клиента и отправляет ответы.

Клиент может отправить несколько команд подряд. Команды разделяются символом QChar(1), поэтому сервер должен обработать каждую команду отдельно.
