QByteArray auth ( const QString & log,
const QString & pass,
qintptr socketId )

Проверяет данные пользователя и формирует ответ авторизации.

Выполняет авторизацию пользователя.

При успешной авторизации возвращает данные профиля: отображаемое имя, идентификатор пользователя, очки, монеты, уровень, выбранные предметы, опыт, роль и дескриптор сокета.

Аргументы
logЛогин пользователя.
passПароль пользователя.
socketIdДескриптор клиентского сокета.
Возвращает
Ответ auth_success или auth_failed с причиной ошибки.

QByteArray parsing ( const QString & data_from_client,

Обрабатывает строковую команду клиента.

Разбирает входящую команду клиента и вызывает нужную серверную операцию.

Функция очищает входные данные, извлекает имя команды и параметры, затем вызывает методы DataBase или вспомогательные функции auth()/reg().

Аргументы
data_from_clientКоманда от клиента.
socketIdДескриптор сокета клиента.
Возвращает
Ответ сервера в виде QByteArray.

Обрабатывает строковую команду клиента.

Входная строка содержит имя команды и параметры, разделённые символом &. Например: auth&login&password.

Аргументы
data_from_clientИсходная строка, полученная от клиента.
socketIdДескриптор сокета клиента, используется в ответе авторизации.
Возвращает
Ответ сервера в формате QByteArray.
